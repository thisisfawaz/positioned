# Positioned.pro

Show your work. Get discovered.

## About

Positioned.pro is a professional talent discovery network where professionals showcase real work and recruiters discover people based on demonstrated ability.

## Core Loop

Show work -> Get discovered -> Get contacted -> Get opportunity

## Features

- Professional profiles with skills and experience
- Structured work posts (Project Showcase, Case Study, Achievement, Work Sample)
- Availability status
- Visibility analytics
- Paid visibility boosts
- Talent search and filters
- Save system for recruiters
- Recruiter verification

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- PostgreSQL with Prisma
- JWT authentication
- Abstracted AI, payment, and storage services

## Getting Started

1. Install dependencies: npm install
2. Set up environment: cp .env.local .env
3. Configure database: npx prisma generate && npx prisma migrate dev --name init
4. Start dev server: npm run dev
5. Open http://localhost:3000

## Design System

- Primary: White (#FFFFFF) and Near-black (#171717)
- Typography: DM Sans and DM Mono
- SVG icons only
- Minimal, professional, editorial aesthetic
